# Hi, I'm Gonçalo 👋

I work across **product and software engineering**, from customer conversations to code. Currently building AI products at **ByTheLaw**.

Outside work, I build tools I actually use: a better way to read my newsletters, manage my finances, and occasionally remember to look away from a screen.

### What I work on

- 📰 **Newsboard** — An Android app that turns my email newsletters into a Flipboard-inspired reading experience. Connected to Hermes through an authenticated backend and a Python worker with queued tasks and retries.
- 💰 **MyFinances** — A personal finance platform for investments, budgets, and multi-currency reporting. Includes an authenticated API and CLI for agent access, with scoped permissions, dry-run validation, and audit logs.
- 👀 **LookFar** — A native macOS eye-break app built with Swift and SwiftUI. Context-aware pauses, multi-display break overlays, and locally stored app and website usage statistics.
- 📸 **Recor** — A native macOS screenshot and annotation app built with Swift, SwiftUI, and AppKit. Capture areas, windows, or entire screens, annotate images, and extract text with on-device OCR. Connected to my personal cloud through Tailscale for storing and accessing screenshots across devices.
- 🤖 **AI-assisted development** — Using Claude Code and Codex to implement, test, and review software, while keeping responsibility for scope and technical decisions.
- 🔧 **Personal automation** — Configuring Hermes with reusable skills, scheduled workflows, and authenticated integrations with my applications.
